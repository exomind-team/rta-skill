# Optional evidence retrieval

Use when repeatedly locating a paragraph, slide page, frame or OCR passage is
costly. Skip this route when direct file reading is simpler. The local index is a
rebuildable cache of known records, not a prerequisite, a knowledge authority, a
library crawler, or a source of publication approval.

## Build from existing source records

Normalize the needed part of an existing ASR, OCR, slide or frame manifest to JSONL.
Do not rerun OCR/ASR just to feed the index. Keep an original manifest reference in
extra fields when useful. A synthetic record could be:

```json
{"id":"slide-a-p3","source_id":"deck-a","kind":"slide","locator":{"page":3,"sample_time":null,"time_status":"unknown"},"text":"保存后，结果显示在列表中。","text_origin":"ocr_candidate","path":"assets/p3.png","status":"candidate"}
```

Required fields are `id`, `source_id`, `kind` and a nonempty `locator` object.
For a source-level record use `{"scope":"source"}` rather than inventing a page.
Kinds and additional metadata are open-ended; useful fields include text/caption
origin, original URL, source/derived-from relationships and an actual asset SHA-256.
Relative local paths resolve beside the JSONL input. An image without OCR/alt text
can still be registered without inventing its meaning.

```bash
python scripts/evidence_index.py build --records /project/units.jsonl --output /project/cache/evidence-v1.sqlite
python scripts/evidence_index.py search --index /project/cache/evidence-v1.sqlite --query "保存 结果" --limit 5
python scripts/evidence_index.py search --index /project/cache/evidence-v1.sqlite --query "保存" --source deck-a --verify
```

The builder validates records before publishing an exclusive new cache path. It
does not overwrite an existing index. It uses same-directory hard-link publication;
unsupported filesystems fail rather than falling back to a destructive replacement.
No media is copied, no model is started, and no information is uploaded.

## Interpret results correctly

- Retrieval uses normalized, case-insensitive literal terms with AND matching.
  Chinese literal phrases work directly; separate terms with spaces. This first
  helper does not claim embedding/semantic retrieval or probability-like confidence.
- Search keeps only the requested top results in memory and bounds output. Each result retains the supplied source ID, locator,
  text origin, editorial status and lineage metadata. Verify that a candidate
  actually teaches the neighboring paragraph before inserting it into a book.
- Held/excluded/retracted/superseded records are omitted from ordinary queries;
  `--include-held` exposes them for deliberate source/selection review. It does
  not authorize publication or resolve a privacy hold.
- Missing or altered assets remain explicit. `--verify` hashes only returned
  local assets with supplied SHA-256 values. A supplied accepted status does not
  override a stale/missing asset and is never generated by the index itself.
- A missing index returns `NOT_PRESENT`; continue from actual source files. A
  search miss means the query/cache had no match, not that teaching content is absent.

Use the verified original page/frame for the final EPUB; OCR and descriptions are
retrieval aids. Preserve meaningful annotations and progressive states even when
their OCR strings are almost identical. Never infer a video time from file order.
Build/edit this cache only when it saves actual work; do not make indexing all
materials a new front-loaded publishing stage. Telemetry is off by default.
